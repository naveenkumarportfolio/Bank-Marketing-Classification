IMPORTANT OBSERVATIONS
----------------------------------------------------------------------
- The 'duration' column (last call duration) is known only
  AFTER a call takes place, so a model using it cannot be
  used to decide who to call BEFORE the call happens. It is
  kept in this academic exercise because the assignment asks
  for a general classification comparison, but this caveat
  should be mentioned when discussing real-world deployment.
- Decision Tree feature importance reflects contribution to
  the tree's splits, not proof of a causal relationship.
- Accuracy alone can be misleading when classes are
  imbalanced, which is why precision, recall and F1-score
  were reported for every model.
